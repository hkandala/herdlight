The design rests on the files in the repository's `resources/` folder. The
repository is private; these links work for people with access.

For a visual overview, open the [interactive overview](/overview/index.html)
(the published `resources/design.html`): mock-ups of the main screens.

Research files may describe earlier designs. These docs win.
