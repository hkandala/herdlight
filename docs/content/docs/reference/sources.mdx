The design rests on the files in `resources/` next to these docs. For a visual overview, open
`resources/design.html`: interactive mock-ups of every screen described here. The research
notes, measurements and spikes are in `resources/research/`, and the inspiration write-ups and
frames are in `resources/inspirations/`.

| File | Covers |
|---|---|
| `resources/design.html` | the interactive visual overview: mock-ups of every screen |
| `resources/research/herdr-core.md` | herdr's socket API, events, layout, remote machines, live tests |
| `resources/research/primary-repos.md`, `macos-clients.md`, `mobile-clients.md`, `web-clients.md` | the existing herdr clients |
| `resources/research/repo-list.md` | every herdr client found |
| `resources/research/plugin-system-v2.md` | the plugin system: options, measurements, manifest, state, API, security |
| `resources/research/floating-panes.md` | what floats in herdr and the floating pane design |
| `resources/research/floating-panels.md` | building the pill panel on macOS, with a working test build |
| `resources/inspirations/INSPIRATIONS.md`, `resources/inspirations/ONE.md` | Cube, Rex and One, frame by frame |
