---
title: "Theme"
description: "Dark only: opaque window and cards, glass on chrome"
---

- Dark only. The window background is opaque near-black (`#0e0f12`), so no
  wallpaper colour shows through. Pane cards are opaque dark. The sidebar and
  tab bar use dark-tinted glass.
- Terminals use a dark palette. Web pages are told `prefers-color-scheme:
  dark`. iOS uses the same look.
- The status glyphs and words are the same everywhere (sidebar, tabs, status
  area, pills, notifications): ◔ working (blue), ▲ needs you (amber),
  ✓ finished (green). "Needs you" is herdr's `blocked` status; "finished"
  means finished and not yet seen. Idle agents show no glyph.
