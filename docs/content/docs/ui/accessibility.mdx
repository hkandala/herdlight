---
title: "Accessibility"
description: "Keyboard paths, VoiceOver labels and motion settings"
---

- Every swipe has a keyboard path, a menu path and a button.
- Status is always a glyph plus a word, never colour alone. VoiceOver reads,
  for example, "codex, needs you, infra".
- Hover controls are also in context menus and the menu bar.
- Reduce Motion turns off the glass morph, page animations and the pill's
  slide. Reduce Transparency is handled by the system glass.
