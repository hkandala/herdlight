---
title: "Drag and drop"
description: "Moving panes by dragging their header"
---

Drag a card by its header:
| Drop on | Result |
|---|---|
| the centre of a card in the same tab | swap the two panes |
| an edge of a card in another tab | split there |
| a tab capsule (hold to page to it) | move into that tab |
| a workspace in the sidebar | new tab in that workspace |
| empty sidebar space | new workspace |
| the `⧉` button | float the pane ([Floating panes](/docs/ui/floating-panes)) |

- The card menu has the same moves (**Move to ▸**, **Float**). That is the
  only path on iPhone.
- A pane cannot move to another machine. Inside one tab only swap is offered.
