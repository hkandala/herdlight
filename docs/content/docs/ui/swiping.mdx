---
title: "Swiping"
description: "Machine pages in the sidebar and tab pages in the strip"
---

<SwipeDiagram />

- Two-finger swipe on a trackpad, one finger on iOS. Pages snap.
- First visit to a machine: the app shows herdr's focused workspace and its
  active tab. Later visits: the workspace and tab the user last picked there.
- Every swipe also has a keyboard path, a menu path and a button. The keys are
  in [Keyboard shortcuts](/docs/ui/theme-and-accessibility#keyboard-shortcuts).

How it works: [Making the strip work](/docs/platform#making-the-strip-work),
[Tab bar and Liquid Glass](/docs/platform#tab-bar-and-liquid-glass).
