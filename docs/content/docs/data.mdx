---
title: "Data: app vs herdr"
description: "What the app stores and what herdr owns"
---

| Data | Owner | Where |
|---|---|---|
| Workspaces, tabs, panes, order, labels | herdr | `session.snapshot` |
| Split tree and ratios | herdr | `snapshot.layouts[]` |
| Terminal content and PTY | herdr | `terminal session` frames |
| Agent kind, status, completion counter, transcript pointer | herdr | `agents[]`, `panes[]` |
| Which panes float | herdr | a tab labelled `hl:float` |
| Web page address | herdr | pane label `web:<url>` |
| Plugin, pane kind, instance id, argument | herdr | pane label `hl:<plugin>[/<pane>]#<iid> <arg>` |
| Plugin instance state | the machine | `$HOME/.local/state/herdlight/<session>/<plugin>/<iid>.json`, with `$HOME` read once on connect ([State and restore](/docs/plugins/state)) |
| Chat history | the agent | its transcript file on the machine |
| Machines (macOS) | herdr | `herdr session list`, `herdr machine list` |
| Machines (iOS): target, session, label, id | app, disk | `UserDefaults` |
| iOS SSH key and pinned host keys | app, disk | Secure Enclave, Keychain |
| Display preferences, pill settings | app, disk | `UserDefaults` |
| Window restore ids (machine, workspace, tab), sidebar expand state | app, disk | `@SceneStorage` |
| Plugin code and source record | app, disk | `Application Support/Herdlight/plugins/` |
| Plugin consent and This Mac answers | app, disk | `UserDefaults` |
| Plugin preferences | app, disk | `UserDefaults`, passwords in the Keychain |
| Approved web origins per machine | app, disk | `UserDefaults` |
| Web cookies | WebKit | one data store per machine |
| Zoomed card, floating card frames, chat or terminal per pane, seen values, drafts | app | memory |
| ControlMaster sockets, port forwards | app | `~/Library/Caches/hl/`, while running |

<Callout title="Nothing the app saves describes herdr's state">
Nothing the app saves describes herdr's state. A restore id that is gone
falls back to herdr's focused workspace. A fresh install on a new device
rebuilds every workspace, tab, pane, floating pane, web page and plugin pane
from herdr's labels and the machines' state files ([State and restore](/docs/plugins/state)).
</Callout>
